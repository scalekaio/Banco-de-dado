# Cão Obediente em 7 Dias

Landing page de vendas do guia digital de adestramento positivo, construída em um único arquivo HTML com CSS e JavaScript embutidos.

## Ver online

A página é publicada pelo GitHub Pages em:

**https://scalekaio.github.io/cao-obediente-em-7-dias/**

## Arquivo principal

- `index.html`: página completa, responsiva e pronta para publicar.

## Configurar o checkout

No final do `index.html`, procure:

```js
const CHECKOUT_URL = "[COLE_AQUI_O_LINK]";
```

Substitua o placeholder pelo link real do checkout. Todos os botões de compra usam essa configuração.

## Antes de publicar

- Substitua os depoimentos de exemplo por relatos reais e autorizados.
- Revise os Termos de Uso e a Política de Privacidade conforme a sua operação.
- As fotos são carregadas do Pexels e do Unsplash; por isso, é necessária conexão com a internet.

## Recursos

- Layout mobile first
- Imagens com lazy-load
- Mockup do ebook em CSS
- Contador regressivo de 15 minutos
- FAQ em acordeão
- CTA fixo no celular
- Modais de Termos e Privacidade
- Acessibilidade e suporte a redução de movimento
